# API Contracts

## 1. Objetivo
Definir a comunicação entre backend e as diversas interfaces.

## 2. Conteúdo Mínimo
Endpoints, Schemas de Input/Output, Códigos de Erro.

## 3. Quem deve consultar
Agentes de IA (Backend/Frontend), Desenvolvedores Mobile.

## 4. Quais decisões ele controla
Formato dos dados trafegados e nomes de campos.

## 5. Alterações que exigem validação humana
Alteração em campos obrigatórios ou mudança de endpoints existentes.
